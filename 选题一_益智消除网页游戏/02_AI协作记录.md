## 4. AI 产出处理明细（采纳 / 修改 / 否决）

### 4.1 否决（AI 建议或被评估的方案，人工裁决不采用）

| # | 内容 | 来源 | 否决理由 |
| --- | --- | --- | --- |
| R-1 | 纯合成玩法（2048 式两两合并）作为第二玩法 | 选题原文"消除/合成"的一种解读 | 与三消框架冲突；学习成本与开发量双高，违背"轻量"定位。**改采**："消除为主、合成为辅"——特定形状消除"合成"特殊方块（FR-04） |
| R-2 | 在线排行榜 + 账号系统 | AI 初稿方案（满足"排行榜"的常见做法） | 与"纯单机、无服务器"定位矛盾，需账号与服务器成本。**改采**：本地排行榜 + 显式信任模型（FR-10-4） |
| R-3 | 广告变现、内购道具、体力系统 | 主流休闲游戏惯例 | 三者是目标用户痛点来源（《羊了个羊》舆论佐证），违背定位，且课程项目无法运营。列入范围外 |
| R-4 | 每日挑战 / 无尽模式 / 计时模式 | 同类产品常见玩法 | 制造时间压力或内容负担，与休闲定位冲突，属范围蔓延。列入范围外（V1.1 候选） |
| R-5 | 玩家关卡编辑器 | AI 头脑风暴候选 | 开发量大，对目标用户无意义。列入范围外 |
| R-6 | 局内状态持久化（刷新后恢复进行中的棋盘） | AI 初稿为"完整性"提出 | 状态序列化与恢复逻辑复杂、易出 Bug，收益低（单局 ≤8 分钟）。**改采**：刷新后该关重置，关卡进度保留，代价显式告知（FR-11-2） |
| R-7 | 好友对战 / 好友排行榜 / 社交平台 SDK | 选题中"社交/分享"的扩展解读 | 超出"分享成绩"最小闭环，开发量不可控。分享仅保留成绩卡 + 复制文本（FR-17，P3） |

### 4.2 修改（AI 初稿内容，经人工审阅后修正）

| # | 初稿问题 | 修改后 | 理由 |
| --- | --- | --- | --- |
| M-1 | 星级规则含糊："剩余步数越多星越高"，消除型关卡无法套用 | 统一为得分比率 R = 结算总分 / scoreTarget（1.0 / 1.3 / 1.6 三档），两类目标关卡通用；消除型关卡的 scoreTarget 独立配置 | 消除歧义，可复算、可验证（AC-14） |
| M-2 | 过关判定时机表述不清（"可继续消耗步数不可逆"） | 明确：每次连锁结束时判定，达成立即结算 | 消除二义性 |
| M-3 | 关卡配置 `scoreTarget` 约束写错（要求 ≥ 方块数目标，单位不同） | 分目标类型定义：score 型相等；clear 型独立配置 | 配置校验规则自洽 |
| M-4 | 第 3 章棋盘"8×8 或 9×9"有歧义 | 改为"8×8~9×9（逐关配置）" | 措辞精确 |
| M-5 | 未明确过关判定是否含剩余步数奖励 | 补充：判定用局内得分/消除计数，奖励仅计入结算总分影响星级 | 防止计分循环定义 |
| M-6 | 特殊方块计分规则缺漏（彩虹消除全屏是否计分） | 明确：范围效果清除的方块正常计分并计入消除目标（FR-04-4） | 计分可复算（AC-13） |
| M-7 | 锤子道具能否刷分未定义 | 明确：计入消除目标数量但不计分，特殊方块不触发（FR-09、FR-04 异常） | 堵住刷分漏洞 |
| M-8 | 关卡配置曾要求"行列乘积为偶数" | 删除该约束 | 经不起推敲：7×7=49 为奇数，主流三消（开心消消乐）即 7×7，奇数棋盘不影响玩法 |
| M-9 | 核实工具只有"聊天式访谈问题"（《04》） | 升级为"结构化单选/多选调查问卷"（《05》，19 题 + 开放题），《04》降级为可选深度访谈工具 | 聊天式访谈无法批量发放与量化统计；结构化问卷可回收 8~10 份，按占比判定假设（《06》2.2/2.3），且题号与核实项 V-02~V-13 一一对应，便于追溯 |
| M-10 | 核实体系以"问卷访谈"为必做项（V-02~V-13 均挂问卷题号） | 调整为免访谈体系：经验核实（需求提出者=目标用户，逐条确认 A1~A10）+ 亲测 + 资料复核 + 浏览器实测；问卷工具保留为可选 | 作业未强制访谈/问卷，硬性要求仅为"关键结论经人工核实"；调整后核实成本大幅下降且完全合规 |
| M-11 | 5 处假设与经验核实结果不一致 | AS-01 放宽为 5~10 分钟/15~30 步（FR-05/08、7.1、画像 A 同步）；AS-02 依据改为"轻量无打扰定位"（2.2 同步）；AS-03 表述修正为"移动端优先、手机浏览器游玩可接受"（人工补充澄清：已玩产品为 App/小程序形态，非排斥浏览器）；AS-04 补充低打扰（FR-10 新增规则 6）；AS-05 补充"与关卡规模相关"前提（9.2 云存档行同步）；FR-17 注明分享不设奖励 | 经验核实 A1~A5、A7（2026-09-28）：假设必须与真实用户经验一致，宁可修订也不保留失真假设 |
| M-12 | 参考文献第 4（web.dev）与第 5（GitHub）在核实人网络中无法访问 | 替换为 MDN 中文对应来源（Web Audio API；浏览器存储配额和逐出标准） | 保证需求来源可追溯、可复核（V-01） |
